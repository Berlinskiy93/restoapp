# Проверка макета RestoApp

## Все ли нужные элементы взяты из макета

Да. В текущей реализации сохранены основные элементы макета:

- жёлтая шапка сайта;
- логотип RestoApp;
- основная навигация: «Меню», «Акции», «О нас», «События», «Зоны доставки»;
- телефон и время приёма заказов;
- заголовок «Меню»;
- четыре карточки категорий: «Пицца», «Супы», «Горячие блюда», «Салаты»;
- изображения карточек из папки `images/` проекта.

Дополнительно проверены состояния клавиатурного фокуса, наведение на карточки и отображение на ширине от 320 px.

## Что улучшено

- исправлена битая кодировка русских текстов;
- добавлено описание страницы для поисковых систем;
- карточки стали интерактивными и получили понятное действие «Открыть раздел»;
- добавлены `aria-label`, `aria-current` и корректная семантика навигации;
- сетка адаптируется под планшеты и мобильные устройства;
- убрана фиксированная высота страницы, из-за которой контент мог обрезаться;
- удалено лишнее `font-weight: 700`;
- повторяющиеся цвета, радиус карточек и фокус вынесены в CSS-переменные `:root`;
- сохранён компактный сброс браузерных стилей через `normalize.css`;
- добавлена автоматическая проверка `check-layout.ps1`.

## Как правильно писать название

Название бренда в проекте пишется единообразно: **RestoApp**. Если используется сокращение вроде `MND`, его нужно оставить в одном регистре во всех местах: в HTML, CSS, README и названиях файлов. Для обычных слов лучше использовать понятные имена в `kebab-case`, например `hot-dishes`, а не случайное смешение `MND`, `mnd` и `Mnd`.

## Доступность

Навигация и карточки сделаны обычными ссылками, поэтому они доступны через `Tab`. Для интерактивных элементов добавлен видимый `:focus-visible`, а `aria-label` используется там, где он действительно нужен. Лишний `tabindex` не добавляется: положительные значения могут нарушить естественный порядок перехода.

## Автоматическая проверка

Запустить из PowerShell в корне проекта:

```powershell
.\тесты\check-layout.ps1
```

## Ручной чек-лист

1. Открыть `index.html` в браузере.
2. Проверить ширину 1440 px: четыре карточки в одну строку.
3. Проверить ширину 768 px: две карточки в строку.
4. Проверить ширину 320 px: одна карточка в строку, без горизонтального обрезания страницы.
5. Перейти по карточкам с клавиатуры клавишей `Tab` и убедиться, что виден фокус.
