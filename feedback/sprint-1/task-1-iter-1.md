Видно, что автор понимает современный CSS и семантику. Молодец! 👏

### БАГИ 🐞

Критические

Неверный min-width (320px вместо 1440px) + overflow-x: hidden.

ТЗ: «Минимальная ширина экрана 1440px, т. е. при меньшей ширине экрана появляется горизонтальный скролл».

В работе: html { min-width: 320px; }, body { min-width: 320px; overflow-x: hidden; }.

Это прямое нарушение ТЗ. Нужно: min-width: 1440px и убрать overflow-x: hidden, чтобы скролл появлялся.

Критично, т.к. это один из явных пунктов ТЗ и чек-листа (п.7).

body { height: 520px; } — жёсткая высота.

Ломает страницу при добавлении контента (следующие задачи). Приводит к обрезке/переполнению.

Критично для дальнейшей разработки.

Адаптивные media-запросы (max-width: 1024px, max-width: 600px) противоречат ТЗ.

ТЗ требует фиксированную минимальную ширину 1440px и горизонтальный скролл, а не адаптив. Эти медиа-запросы «спасают» от скролла, что противоположно требованию.

Критично в связке с п.1.

🟡 Небольшие

normalize.css подключён отдельным `<link>`, а не через @import в style.css.

ТЗ: «важно импортировать все стили в style.css». Формально рекомендация, но лучше соблюсти.

Небольшой баг.

font-family в body — Arial, а не Inter.

Inter применяется точечно, но базовый шрифт body — Arial. Для консистентности лучше font-family: Inter, Arial, Helvetica, sans-serif; в body.

Небольшой баг / улучшение.

Жёсткие ширины в .nav-list li:nth-child(n).

Хрупко: при изменении шрифта/текста ширины не совпадут. Избыточно, т.к. есть flex: 0 0 auto и white-space: nowrap.

Небольшой баг / рекомендация.

.menu h1 — не сброшен margin из normalize.css полностью.

В normalize.css h1 { margin: 0.67em 0; }, в style.css margin: 0 0 32px; — ок, сброшено. ✅ (не баг, просто проверил)

Контейнер max-width: 1312px — нужно сверить с макетом. Если в макете 1440px контентная часть — то неверно. Если 1312px — ок. По ТЗ «при ширине больше 1440px контент по центру» — 1312px центрируется, это допустимо, но стоит сверить с макетом.

### РЕКОМЕНДАЦИИ 💡

Исправить min-width и overflow:

css

html {

min-width: 1440px;

}

body {

min-width: 1440px;

/\* overflow-x: hidden; — УБРАТЬ \*/

}

И удалить media-запросы max-width: 1024px / max-width: 600px (они противоречат ТЗ). Если хочется адаптива — это будет в следующих задачах, но сейчас ТЗ требует фиксированную ширину со скроллом.

Убрать height: 520px из body. Высота должна определяться контентом.

Импортировать normalize через style.css:

css

@import './normalize.css';

И убрать отдельный `<link>` из index.html (или оставить, но ТЗ просит импорт в style.css).

Поставить Inter базовым шрифтом:

css

body {

font-family: Inter, Arial, Helvetica, sans-serif;

}

Убрать жёсткие nth-child ширины из .nav-list li — они избыточны. Оставить flex: 0 0 auto и white-space: nowrap.

Сверить max-width: 1312px и font-size: 40px у h1 с макетом. Возможно, контейнер 1440px, а h1 крупнее.
